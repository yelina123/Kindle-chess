# Kindle 小应用

给 Kindle 第八代（600×800、16 级灰阶、WebKit 531 时代浏览器）等低算力黑白墨水屏设备做的单文件网页小应用。每个项目一个目录、一个 HTML 文件；核心对局完全离线，只用点按操作。

在线入口：<https://yelina123.github.io/Kindle-chess/>

## 项目

| 项目 | 目录 | 在线入口 | 说明 |
| --- | --- | --- | --- |
| 国际象棋 | `chess/` | <https://yelina123.github.io/Kindle-chess/chess/> | 完整规则、棋钟与加时、棋盘编辑器、神经网络/经典引擎可切换、云端局面分析（含任意 FEN） |
| 中国象棋 | `xiangqi/` | <https://yelina123.github.io/Kindle-chess/xiangqi/> | 完整规则、点按走子、棋钟/加时/暂停、悔棋、翻转、六档本地人机、局面分析、棋谱折叠页 |

两个项目在本地运行时是两个彼此独立的 HTML 文件；GitHub Pages 上通过根目录 `index.html` 选择进入哪一个。仓库里不再保留旧的 `kindle-chess.html`，国际象棋统一走 `chess/`。

## 中国象棋

单个 HTML 约 150 KB，自包含，不依赖外部图片、字体、脚本或 CDN。目标是 Kindle 第八代这类低算力黑白墨水屏设备。

### 对局页

- **棋盘优先**：对局页只有「状态条 + 大棋盘 + 单行工具栏」。棋盘 540×600，比旧版放大约 30%，右侧不再有常驻信息栏。
- **状态条**：左边黑底标签写明「线下 · 双人」或「人机 · 执红 · 中级」，点它直接进模式页；中间是轮次与「将军」提示；右边是双方剩余时间，点它打开棋钟面板。
- **工具栏单行**：新局、悔棋、翻转、提示、分析、棋谱、更多（模式与棋力 / 棋钟 / 规则 / 设置）。
- **棋谱不占棋盘**：着法收进独立的「棋谱」二级页，按回合分页（每页 15 回合），用传统记谱（炮八平五、马2进3，同列同子自动加前/后）。

### 引擎

- 六档棋力，每档都写明层数与时间上限：

| 档位 | 层数 | 时间上限 | 特点 |
| --- | --- | --- | --- |
| 入门 | 1 | 0.3 秒 | 只看一步，常走软着 |
| 初级 | 2 | 0.7 秒 | 会吃白送的子 |
| 中级 | 3 | 1.8 秒 | 有基本战术 |
| 较强 | 4 | 3.5 秒 | 算得较深 |
| 强 | 5 | 7 秒 | 会算杀 |
| 大师 | 7 | 14 秒 | 限时深算，Kindle 上较慢 |

- 引擎 v2：迭代加深、Zobrist 置换表、PVS 主变搜索、吃子静态搜索、杀手着法/历史启发、空着裁剪、被将延伸、增量哈希、从帅位反向探测的快速将军判断。
- 评估含子力、位置表、缺士缺象惩罚与先手之利；不是神经网络，也不联网。

### 局面分析

- 评分（红方视角）、胜率条、最佳着法、前四条候选着法与分数、主变（PV）、深度/节点/耗时/速度。
- 页面同时给出缩略棋盘，分析时棋钟冻结，返回对局才继续。
- 「再深一层」逐层加深（最高 7 层），「走这步」直接把最佳着法落到棋盘上。
- 面板明确标注「本机 Alpha-Beta 引擎，非神经网络，不联网」；胜率条只出现在分析页。

### 其它

- 9 列 × 10 行完整棋盘，红方在下、黑方在上、红先；帅/将、仕/士、相/象、马、车、炮、兵/卒完整走法，含九宫、河界、马腿、象眼、炮架、将帅照面。
- 点棋子，再点目标交点走子；选中后显示所有合法目标（空格黑点、可吃子黑圈）。
- 将军、将杀、困毙判定；棋钟基础时间 + 每步加时，可暂停、单方加时、关闭，倒计时按 1/5/10 秒刷新。
- 悔棋（人机模式一次退回双方各一步）、翻转视角、提示一步。
- 断点续局：局面、棋谱、棋钟、模式、翻转方向保存到浏览器 localStorage。

### 规则说明

- 初始局面 perft 已验证：1 层 44、2 层 1920、3 层 79666。
- 已验证将杀、困毙、将帅照面、马腿、象眼、炮架、兵过河等特殊局面。
- 三次重复局面判和；若重复局面全部发生在被将军状态，则判长将方负。连续 120 个半回合（60 回合）无吃子判和。这是面向触控对弈的简化实现，不是完整竞赛棋例；规则页已写明。

## 国际象棋

- 6 种棋子完整走法、吃过路兵、升变、易位、将军/将杀/逼和/五十回合/三次重复/子力不足。
- 点棋子再点目标格；升变弹出选择；棋盘编辑器；棋钟；断点续局。
- **编辑器出口可选**：从编辑器继续时不再直接回原模式，而是先问这一局怎么下——「人机 · 我执白」「人机 · 我执黑」「两人同屏」，另有「继续编辑」「放弃修改」；棋盘、先手与易位都按编辑器当前设置。
- **引擎可切换**：设置里「人机引擎」与「局面分析」各有一档「神经网络 / 经典本地」。神经网络 = 云端 Stockfish（NNUE），经典 = 本机 Negamax。Kindle、窄屏等弱设备默认关闭神经网络，其他设备默认开启；两档互相独立。
- **任意局面云分析**：残局库（≤7 子）→ Lichess Cloud Eval → stockfish.online 深算该 FEN（云库未收录时）→ 本地浅层搜索。人机对弈同样会在云库缺失时用 stockfish.online，仍失败才回退经典档位。
- 局面分析：白方视角评分、最佳着法、前三候选、胜率条、深度/节点/耗时。
- 云功能只发送局面，不登录、不上传棋谱；需要联网，核心对局离线可玩。

## 本地使用

- 国际象棋：打开 `chess/index.html`。
- 中国象棋：打开 `xiangqi/index.html`。
- 两者互不合并；在 Kindle 上可以通过文件管理器分别打开，也可以把整个目录放到局域网静态服务器。
