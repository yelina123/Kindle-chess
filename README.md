# Kindle 小应用

给 Kindle 第八代（600×800、16 级灰阶、WebKit 531 时代浏览器）等低算力黑白墨水屏设备做的单文件网页小应用。每个项目一个目录，一个 HTML 文件；核心对局完全离线，只用点按操作。云引擎/云分析为可选功能，失败会自动回退本地。

在线入口：<https://yelina123.github.io/Kindle-chess/>

## 项目

| 项目 | 目录 | 说明 |
| --- | --- | --- |
| 国际象棋 | `chess/` | 完整规则、棋钟与加时、棋盘编辑器、本地/云分析、本地/云人机对弈 |
| 中国象棋 | `xiangqi/` | 预留位置，由另一个项目接入；当前没有可玩页面 |

### 国际象棋

- 在线：<https://yelina123.github.io/Kindle-chess/chess/>
- 旧地址 `kindle-chess.html` 会自动跳转到 `chess/`
- 6 种棋子完整走法、吃过路兵、升变、易位、将军/将杀/逼和/五十回合/三次重复/子力不足
- 点棋子再点目标格，全部操作使用点按；升变弹出选择
- 棋钟：基础时间、每步加时、暂停/继续、给任一方加时
- 棋盘编辑器：摆子、载入 FEN、设置先手与易位，再开始对局
- 局面分析：白方视角评分、最佳着法、前三候选、胜率条、节点/耗时；本地深度 2–4 层可选
- 人机对弈：云 Stockfish 优先；本地入门、初级、中级、较强、强五档作为回退
- 断点续局：浏览器 localStorage 保存当前局面与设置
- 棋盘与棋子：Cburnett 棋具（来自 lichess，CC BY-SA 3.0），已栅格化为内联 PNG
- 单文件约 148 KB；核心对局不请求外部资源

模式说明：工具栏「模式」页单独设置线下对弈/人机对弈、你执哪一方、引擎来源（云/本地）、本地回退棋力；对局右侧状态栏顶部始终显示当前模式。切换模式会开始新局。

### 云引擎与云分析

- 人机对弈的云引擎使用 **Lichess Cloud Eval**（Lichess 服务端 Stockfish NNUE）返回的当前局面最佳着法；不需要 Lichess 账号，也不需要 OAuth/Board API。
- 云分析同样优先请求 Lichess Cloud Eval；≤7 子残局先查 **Lichess Tablebase**。
- Lichess Cloud Eval 只对 Lichess 已缓存的局面返回结果；未收录时返回 404，本应用会自动回退到当前本地档位/本地深度。
- 网络不可用、跨域失败、超时或服务报错时也会回退本地；连续失败会暂时停用云请求，避免每一步都等待。
- 云结果按局面缓存到 localStorage，重复查看/重复对局更快；缓存不含账号信息。
- 云 Stockfish 是完整强度，可能明显强于本地档位；想下得轻松些可在「模式」页把引擎切到「本地」。
- 本应用只请求评估结果，不发起 Lichess 好友对局、不登录、不上传棋谱。云功能需要联网；核心对局离线可玩。

分析说明：分析面板标题会显示本次实际使用的模型（`Lichess Cloud Eval · Stockfish NNUE`、`Lichess Tablebase` 或 `内置 KindleChess Engine v1`）。本地引擎为 Negamax + Alpha-Beta + 吃子静态搜索，非神经网络；深度 4 在 Kindle 上可能很慢，结果会回退到已完成的最深一层。胜率条只在分析结果中出现。

## 目录结构

```
/
├── index.html          仓库入口（项目列表）
├── kindle-chess.html   旧链接跳转页
├── chess/
│   └── index.html      国际象棋（单文件，自包含）
├── xiangqi/
│   └── README.md       中国象棋预留位置（等待另一个项目接入）
├── README.md
└── .nojekyll
```

后续新增项目时，在仓库根目录下新建语义化目录（例如 `xiangqi/`），放入该项目的 `index.html`，并在根 `index.html` 的项目列表中加入入口。`xiangqi/` 当前只有占位说明，避免和另一个 Agent 的成品冲突。

## 兼容

- 目标设备：Kindle 第八代内置浏览器（约 600×800、16 级灰阶、1 GHz 级 CPU）
- 无 flex/grid/`position:fixed`/`calc()`/`vh`/`vw`；只用 click，不依赖 touch 事件
- 页面在切换对局/模式/设置/编辑器/分析面板后，按当前视图真实内容宽高重新等比缩放；16:9 横屏、16:9 竖屏、Kindle 600×800 均完整显示，不横向或纵向滚动
- 棋子为 96×96 PNG 内联，单文件约 148 KB；核心对局不请求外部资源
- 规则核心已用标准局面的 perft 验证（初始局面 20/400/8902/197281 等）
