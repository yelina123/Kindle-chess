# Kindle 小应用

给 Kindle 第八代（600×800、16 级灰阶、WebKit 531 时代浏览器）等低算力黑白墨水屏设备做的单文件网页小应用。每个项目一个目录、一个 HTML 文件；核心对局完全离线，只用点按操作。

在线入口：<https://yelina123.github.io/Kindle-chess/>

## 项目

| 项目 | 目录 | 在线入口 | 说明 |
| --- | --- | --- | --- |
| 国际象棋 | `chess/` | <https://yelina123.github.io/Kindle-chess/chess/> | 完整规则 + 弃子棋/炸弹棋/疯狂屋/山丘之王/三次将军/部落棋六种特殊玩法、棋钟与加时、棋盘编辑器、本地/云分析、本地/云人机对弈；模式/玩法/执子/引擎/时限集中在「新局 / 换模式」页 |
| 中国象棋 | `xiangqi/` | <https://yelina123.github.io/Kindle-chess/xiangqi/> | 完整规则、点按走子、棋钟/加时/暂停/无棋钟模式、悔棋、翻转、提示、上下步回看、六档本地人机、局面分析（胜率 + 候选）、断点续局 |

两个项目在本地运行时是两个彼此独立的 HTML 文件；GitHub Pages 上通过根目录 `index.html` 选择进入哪一个。

旧地址 `kindle-chess.html` 会自动跳转到国际象棋。

## 中国象棋

单个 HTML 约 148–170 KB（国际象棋约 170 KB、中国象棋约 148 KB），自包含，不依赖外部图片、字体、脚本或 CDN。两个页面打开时都先显示介绍页，不自动摆盘，点「新局」才开始。目标是 Kindle 第八代这类低算力黑白墨水屏设备。

### 功能

- 9 列 × 10 行完整棋盘，红方在下、黑方在上、红先。
- 完整棋子规则：帅/将、仕/士、相/象、马、车、炮、兵/卒；九宫、河界、马腿、象眼、炮架、将帅照面。
- 点棋子，再点目标交点走子；选中后显示所有合法目标（空格黑点、可吃子黑圈）。不依赖拖拽或长按。
- 将军、将杀、困毙判定。
- 棋钟：基础时间 + 每步加时；暂停/继续、给任一方加时、关闭棋钟；墨水屏可选择每秒/每 5 秒/每 10 秒刷新一次倒计时。
- 悔棋：线下模式撤回自己一步；人机模式一次撤回电脑和你各一步。
- 翻转视角；提示一步（本地浅层搜索，约 1.2 秒预算）。
- 五档本地人机：入门、初级、中级、较强、强。电脑用子力 + 位置评估 + Alpha-Beta + 吃子静态搜索，不是神经网络，也不联网。
- 断点续局：局面、棋谱、棋钟、模式、翻转方向保存到浏览器 localStorage；下次打开自动恢复。
- 「模式」「棋钟」「规则」「设置」为独立页面，对局状态栏顶部始终显示当前是线下双人还是人机、执哪一方、电脑档位。

### 规则说明

- 初始局面 perft 已验证：1 层 44、2 层 1920、3 层 79666。
- 已验证将杀、困毙、将帅照面、马腿、象眼、炮架、兵过河等特殊局面。
- 三次重复局面判和；若重复局面全部发生在被将军状态，则判长将方负。连续 120 个半回合（60 回合）无吃子判和。这是面向触控对弈的简化实现，不是完整竞赛棋例；规则页已写明。

### 兼容

- 目标设备：Kindle 第八代内置浏览器（约 600×800、16 级灰阶、1 GHz 级 CPU、WebKit 531 时代）。
- 无 flex/grid/`position:fixed`/`calc()`/`vh`/`vw`；无 `let`/`const`/箭头函数/模板字符串/class；无 WebAssembly、Web Worker、fetch。
- 只使用 click，不依赖 touch 事件；所有可点按目标至少 44px。
- 禁用双击与双指缩放，避免 Kindle / 手机浏览器的误触放大。
- 页面按当前实际视口宽高做整体等比缩放，禁止横向或纵向滚动；16:9 横屏、16:9 竖屏、Kindle 600×800 均能完整显示。
- 棋子图是 14 枚 44×44 PNG，内联进 HTML；单文件约 148–170 KB。

## 国际象棋

- 6 种棋子完整走法、吃过路兵、升变、易位、将军/将杀/逼和/五十回合/三次重复/子力不足。
- 点棋子再点目标格；升变弹出选择；棋盘编辑器；棋钟；断点续局。
- 局面分析：白方视角评分、最佳着法、前三候选、胜率条、节点/耗时；本地深度 2–4 层可选。
- 人机对弈：云 Stockfish 优先；本地入门、初级、中级、较强、强五档回退。
- 特殊玩法（在「新局 / 换模式」页先选标准或特殊玩法，再展开具体玩法）：弃子棋（必须吃子、王可被吃、先丢光棋子者胜）、炸弹棋（吃子爆炸、炸掉王即胜）、疯狂屋（被吃子进手里、可放回棋盘、兵不能放底线）、山丘之王（王到中心四格即胜）、三次将军（先将军三次者胜）、部落棋（白方 36 个兵对黑方完整军队）。特殊玩法只用本地引擎与本地分析。
- 双人面对面：设置里打开「两侧坐标」后，线下对局会在棋盘上方和右侧再画一套倒过来的横纵坐标，方便坐在对面的人看。
- 云分析/云引擎使用 Lichess Cloud Eval 和 Lichess Tablebase，仅发送局面，不登录、不发起好友对局、不上传棋谱；未缓存或网络失败时回退本地。
- 云功能需要联网；核心对局离线可玩。

## 本地使用

- 国际象棋：打开 `kindle-chess.html`，或仓库里的 `chess/index.html`。
- 中国象棋：打开 `中国象棋.html`，或仓库里的 `xiangqi/index.html`。
- 两者互不合并；在 Kindle 上可以通过文件管理器分别打开，也可以把整个目录放到局域网静态服务器。
