# 中国象棋 · Kindle 单文件版

给 Kindle 第八代（600×800、16 级灰阶、WebKit 531 时代浏览器）等低算力黑白墨水屏设备做的中国象棋。整页只有一个自包含 HTML：`index.html`，不请求外部图片、字体、脚本或 CDN，离线可玩。

在线：<https://yelina123.github.io/Kindle-chess/xiangqi/>

本地：打开仓库根目录外的 `中国象棋.html`，或直接打开本目录 `index.html`。

## 内容

- 9 列 × 10 行完整棋盘，红方在下、黑方在上、红先。
- 帅/将、仕/士、相/象、马、车、炮、兵/卒完整走法；九宫、河界、马腿、象眼、炮架、将帅照面。
- 点棋子，再点目标交点走子；选中后显示合法目标（空格黑点、可吃子黑圈）。只用 click，不依赖拖拽或长按。
- 将军、将杀、困毙判定。
- 棋钟：基础时间 + 每步加时；暂停/继续、给任一方加时或减时（±1/±5/±10 分，加减时在同一面板）、开关棋钟；减时最低保留 10 秒，会拦下更低的减法以防误加时后减不回去。倒计时默认每秒刷新（也可设为每 5/10 秒省电）。**第一步落子后才开始计时**，刚进页面或刚重开一局时棋钟是静止的。
- 上方按钮「新局 / 换模式」直接进「开新局」页（不再单独放「模式」按钮）：模式（线下双人 / 人机）、执子与棋力、计时方式（有棋钟 / 无限时）、时限（预设或自定义）都在这一页，点「开始」按这些设置重开。切换模式也算开新局，棋钟按设定时限重置，不会带着上一局的剩余时间；对局中的棋钟面板也能直接开关棋钟。
- 时限设置是「预设 / 自定义」二选一：选预设就只显示 5+0、10+0、10+5、15+10、30+0，选自定义才出现基础时间与每步加秒输入框，不会出现预设高亮和自定义数值同时生效的冲突。
- 无棋钟模式：在「开新局」页选「无限时」后，时限选项会隐藏，右侧换成“无限时 / 无棋钟”，工具栏的「棋钟」变成灰掉的「无限时」（点了不会弹出棋钟面板），不计时也不判超时。想恢复计时就回「新局」页选「有棋钟」再开一局。
- 悔棋、翻转视角、提示一步。
- 上下步回看：`上一步 / 下一步` 逐手回放历史局面，`当前局面` 回到最新；回看只读，棋钟暂停，不影响正在进行的对局。
- 六档本地人机：入门、初级、中级、较强、强、强+。引擎 v2 = 迭代加深 + Zobrist 置换表 + PVS + LMR + 空着裁剪 + 吃子静态搜索 + 杀手/历史排序，不联网。
- 按设备给建议：Kindle 类设备默认「中级」并在界面上标注“建议 ≤ 中级”；手机/电脑默认「较强」，可用「强 / 强+」。强+ 是 6 层 / 14 秒预算。
- 局面分析：对当前局面（含回看局面）算深度分、红方胜率百分比与胜率条、最佳着法、前 3 候选着法、节点/耗时/节点每秒，并标注所用模型（本机 Alpha-Beta，非神经网络）与分析强度档。设置页可固定分析引擎档位：自动 / 轻量（深度 4、6 秒预算）/ 强力（深度 7、20 秒预算，适合手机电脑，Kindle 上会明显变慢）。
- 断点续局：局面、棋谱、棋钟、模式、翻转方向保存到 localStorage。
- 模式、棋钟、规则、设置是独立页面；对局右侧始终显示当前模式（线下双人 / 人机、执红/执黑、档位）。

## 规则验证

初始局面 perft：

- 1 层 44
- 2 层 1920
- 3 层 79666

另外验证过将杀、困毙、将帅照面、马腿、象眼、炮架、兵过河等特殊局面。三次重复局面判和；若重复局面全部发生在被将军状态，判长将方负；连续 120 个半回合（60 回合）无吃子判和。这是简化实现，不是完整竞赛棋例，规则页有说明。

- 设置页只剩三项：墨水屏刷新频率、分析引擎档位（自动 / 轻量 / 强力），以及「仓库 / 关于」——仓库地址 <https://github.com/yelina123/Kindle-chess>、在线地址 <https://yelina123.github.io/Kindle-chess/xiangqi/>、作者与引擎/适配说明。

## 兼容

- 无 flex/grid/`position:fixed`/`calc()`/`vh`/`vw`；无 `let`/`const`/箭头函数/模板字符串/class；无 WebAssembly、Web Worker、fetch。
- 只使用 click；可点按目标至少 44px。
- 按当前视口宽高整体等比缩放，`html/body` 锁死不出滚动条；16:9 横屏、16:9 竖屏、Kindle 600×800 均完整显示（实测 600×760、412×892、844×390、1024×768、400×640 无溢出）。
- 14 枚 44×44 PNG 棋子内联在 HTML；单文件约 143 KB。
